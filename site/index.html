Install the extension

Install a local Chrome-compatible extension

Download the reviewed ZIP, then load its unpacked folder in a Chromium browser.

  1. 1
    Download and unzip

    Save the ZIP and expand it to a folder you keep.

  2. 2
    Open extensions

    Visit chrome://extensions and enable Developer mode.

  3. 3
    Load the folder

    Choose Load unpacked and select the expanded folder.

Privacy and limits

Read this before using a glossary

Where does the glossary go?

The extension stores its cards and settings in browser extension storage.

Does the extension send selected text away?

No. Matching and speech use browser APIs on your device.

Can I share a glossary?

Export readable JSON. Import can merge matching terms or replace a glossary.
