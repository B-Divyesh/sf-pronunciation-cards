Questions before you install

Does it send the text I select anywhere?

No. Selection processing, glossary matching, and speech preview happen through browser APIs on your device.

Will it fix every screen reader?

No. Browser extensions cannot reliably change the pronunciation dictionary inside independent screen readers. Use the generated SSML in tools that support it.

Can a team share a glossary?

Yes. Export the versioned JSON file and send it through your usual approved channel. Import can merge by term or replace the current glossary.
